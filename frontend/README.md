# Frontend

React Native + Expo para web/Android/iOS. `npm install` e `npm run web`.
Configure EXPO_PUBLIC_API_URL em .env. Sessão apenas em memória.
Telas Explore, Analytics, Áreas, Desenvolvedores, Sobre e Conta consomem FastAPI.
Mapa integrado ainda pendente; botão abre OpenStreetMap. Áreas são cadastradas por coordenadas.
Não houve validação em dispositivo móvel nesta entrega.
