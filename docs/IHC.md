# Interação humano-computador

## Personas de projeto (hipóteses, não pesquisa concluída)

| Persona | Necessidade | Resposta da interface |
| --- | --- | --- |
| Estudante | Entender LST sem confundir com clima | Explore com texto simples, legenda e aviso sintético |
| Gestor urbano | Marcar lugares e acompanhar visitas | Desenho, data, notas, status e confirmação de exclusão |
| Pesquisador | Reproduzir experimentos e interpretar erro | Dataset versionado, split explícito, métricas e SHAP |
| Desenvolvedor | Consumir dados com contrato previsível | Swagger, API key, cotas e paginação |

## Princípios aplicados

Navegação consistente; rótulos visíveis; alvos com pelo menos 44 px; feedback de
processamento e erros; estados vazios orientados; ações destrutivas confirmadas;
controle explícito sobre modelo/dataset; linguagem científica sem ocultar limitações.
A cor do mapa é acompanhada por legenda e valores numéricos consultáveis.

## Validação pendente

Testes com usuários reais, contraste automatizado de todos os estados, teclado
no mapa, leitores de tela, uso offline e validação em aparelhos Android/iOS.
A adaptação de layout não constitui conformidade WCAG ou ISO certificada.
